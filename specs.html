Map collapse on scroll: iOS spec

As the sheet scrolls up, the map fades out and a glass header with the title fades in. There are two versions. All values come from the prototype and are in points.

Open the interactive demo

Key numbers

0 → 120 ptScroll range for the whole effect
easeInOutQuadCurve for the map fade
70 → 120 ptHeader and title fade in
0 or 120 ptSnap positions on release

The animation is driven by scroll position, not time. y is the scroll offset from rest: contentOffset.y + adjustedContentInset.top. Each value below is a pure function of y, so it follows the finger exactly and reverses when the user scrolls back.

So the map moves at 45% of the scroll speed (parallax) while it fades. The prototype has no overscroll; use max(y, 0) for the parallax unless you want the map to follow a pull-down.

Glass header

  • Use a system material, such as .systemUltraThinMaterial, or the system glass effect on newer iOS. The prototype approximates it with a 14 pt blur at 180% saturation over a white tint that goes from 78% to 62% opacity.
  • Height is 128 pt on a 393 pt wide screen: the status bar, the nav row and a soft tail. The bottom 28% fades to transparent through a gradient mask, so it has no hard edge.
  • Fade it with the alpha of a container view that holds the effect view. Setting alpha on a UIVisualEffectView directly breaks the effect.

Snapping

If the user lets go between the two states, the sheet settles to fully open (y = 0) or docked (y = 120), whichever is closer. The midpoint is 60.

The dock position puts the card's top edge 8 pt below the header, so the whole card is visible: 232 (card top) − 104 (header) − 8 = 120. On device, work it out from the real layout: cardTop − headerMaxY − 8. Outside that range, scrolling is free and nothing snaps.

The web prototype snaps 140 ms after scrolling stops. On iOS it's better to use the projected target in scrollViewWillEndDragging, as in the code below, so a quick flick follows its momentum.

Reference code (UIKit)

func clamp(_ v: CGFloat) -> CGFloat { min(max(v, 0), 1) }
func easeInOutQuad(_ t: CGFloat) -> CGFloat { t < 0.5 ? 2*t*t : 1 - pow(-2*t + 2, 2) / 2 }
func easeOutCubic(_ t: CGFloat) -> CGFloat { 1 - pow(1 - t, 3) }

let fadeEnd: CGFloat = 120, headerSpan: CGFloat = 50, dock: CGFloat = 120

func scrollViewDidScroll(_ sv: UIScrollView) {
    let y = sv.contentOffset.y + sv.adjustedContentInset.top
    let p = easeInOutQuad(clamp(y / fadeEnd))
    let early = clamp(y / (fadeEnd * 0.45))            // 0 → 54

    mapContainer.alpha = 1 - p
    pinsView.alpha = 1 - early
    expandButton.alpha = 1 - early

    if style == .parallaxBlur {
        let lift = -0.45 * max(y, 0)
        let s = 1 + 0.04 * p                            // anchorPoint (0.5, 0)
        mapContainer.transform = CGAffineTransform(scaleX: s, y: s)
            .concatenating(CGAffineTransform(translationX: 0, y: lift))
        mapBlur.radius = 6 * p                          // see the note on blur
        let b = 1 - 0.15 * early
        expandButton.transform = CGAffineTransform(scaleX: b, y: b)
            .concatenating(CGAffineTransform(translationX: 0, y: lift))
    }

    let h = clamp((y - (fadeEnd - headerSpan)) / headerSpan)   // 70 → 120
    headerGlassContainer.alpha = h
    let t = easeOutCubic(h)
    titleLabel.alpha = t
    titleLabel.transform = CGAffineTransform(translationX: 0, y: 6 * (1 - t))
}

func scrollViewWillEndDragging(_ sv: UIScrollView, withVelocity v: CGPoint,
                               targetContentOffset target: UnsafeMutablePointer<CGPoint>) {
    let inset = sv.adjustedContentInset.top
    let y = target.pointee.y + inset
    guard y > 0, y < dock else { return }
    target.pointee.y = (y < dock / 2 ? 0 : dock) - inset
}

Blur: UIKit has no blur-radius property. Use SwiftUI .blur(radius:) on the map, a CIGaussianBlur on a map snapshot, or a paused UIViewPropertyAnimator on a blur effect driven by fractionComplete = p. The radius only needs to be close to 6 pt.

Accessibility

  • When Reduce Motion is on, use Fade only, with no parallax, scale or blur.
  • VoiceOver should always be able to read the title, even while it is hidden over the map. Hide it visually, not from accessibility.
